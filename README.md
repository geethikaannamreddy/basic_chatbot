#  🤖 Basic Chatbot

## Overview
This project is a simple rule-based chatbot developed in Python. It responds to predefined user inputs using conditional statements.

## ✨ Features

-  Greets the user
-  Responds to common questions
-  Handles unknown inputs gracefully
-  Exits when the user types **"bye"**
-  Built using core Python concepts

## 🛠️ Technologies Used
- Python 3

##  📚 Concepts Used
- Functions
- While Loop
- If-Elif-Else
- Input and Output
- String Manipulation

## 💡 Example

User: hello
Bot: Hi! Nice to meet you.

User: how are you
Bot: I'm doing great. Thanks for asking!

User: bye
Bot: Goodbye! Have a wonderful day.
